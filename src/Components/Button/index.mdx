# Button 컴포넌트 개요

## 설계 목적
Button 컴포넌트는 다양한 버튼 스타일과 상태를 효율적으로 관리하기 위해 설계되었습니다. 이를 통해 디자인 요구 사항을 충족하고, 재사용 가능한 UI 요소를 제공합니다.

### 주요 목표
- **일관성**: 모든 버튼 스타일이 동일한 규칙을 따릅니다.
- **유지보수성**: 버튼 스타일과 상태를 쉽게 확장하거나 수정할 수 있습니다.
- **재사용성**: 다양한 페이지와 상황에서 동일한 버튼 컴포넌트를 사용할 수 있습니다.

## 구성 요소
Button 컴포넌트는 다음 세 가지 파일로 구성됩니다:

1. **button-data.js**
   - 버튼 스타일과 상태를 정의하는 데이터 파일.
   - `button`, `textButton`, `iconButton` 세 가지 카테고리로 구성.
   - 각 카테고리는 크기(Large, Medium, Small)와 상태(활성화, 비활성화)를 지원.

2. **Button-PC.js**
   - `button-data.js`를 기반으로 버튼을 렌더링하는 컴포넌트.
   - `SinglePage` 함수는 버튼 카테고리와 상태를 받아 HTML과 CSS를 생성.

3. **Button-PC.stories.js**
   - Storybook을 통해 Button 컴포넌트를 테스트하고 문서화.
   - `makeStories` 함수는 버튼 카테고리를 기반으로 스토리를 생성.

## 수정 방법

1. **스타일 변경**
   - `button-data.js`에서 버튼 스타일을 수정.
   - 예: 텍스트 버튼의 색상, 크기, 글꼴 등을 변경.

2. **렌더링 로직 변경**
   - `Button-PC.js`에서 버튼의 HTML 구조나 클래스 이름을 수정.
   - 예: 새로운 버튼 유형을 추가하거나 기존 구조를 변경.

3. **스토리북 업데이트**
   - `Button-PC.stories.js`에서 새로운 버튼 카테고리를 추가하거나 설명을 수정.
